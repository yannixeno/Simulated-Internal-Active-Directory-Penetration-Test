# Simulated-Internal-Active-Directory-Penetration-Test
This repository contains a comprehensive internal penetration testing report conducted against a simulated enterprise Windows and Active Directory environment. The assessment was designed to replicate a real-world adversary’s attack path, beginning with network reconnaissance and service enumeration before progressing into exploitation, credential attacks, privilege escalation, lateral movement, post-exploitation, persistence analysis, and domain compromise.
The assessment covered multiple systems within an internal network, including Windows endpoints and Active Directory domain controllers. Testing identified and demonstrated several significant attack paths, including exploitation of the MS17-010 EternalBlue vulnerability, password spraying against exposed services, Kerberoasting of service accounts, credential recovery through offline password cracking, administrative access, lateral movement through Remote Desktop Protocol, and the creation of unauthorized privileged accounts within the domain.
Tools and techniques used throughout the engagement included Nmap, Metasploit, Meterpreter, Impacket, Hashcat, BloodHound, xfreerdp, SMB enumeration, PowerShell-based system reconnaissance, and Windows privilege and user enumeration. The report documents the methodology used, commands executed, evidence collected, compromised hosts, recovered artifacts, attack paths, and the security impact associated with each finding.
The most significant outcome of the assessment was the compromise of multiple systems and the escalation of access to domain-level administrative privileges. This demonstrated how weaknesses such as outdated systems, legacy SMB services, weak service-account passwords, insufficient account protections, unrestricted administrative access, and inadequate monitoring can be chained together to compromise an entire Windows enterprise environment.
Each finding includes a technical explanation, severity rating, affected systems, reproduction steps, security impact, and recommended remediation. Recommendations include applying missing security patches, disabling SMBv1, enforcing stronger password and account-lockout policies, implementing multi-factor authentication for privileged accounts, auditing service principal names, using Group Managed Service Accounts, restricting administrative RDP access, monitoring privileged group membership, and improving network segmentation and detection capabilities.
This project was completed in an authorized, simulated lab environment for educational and portfolio purposes. It demonstrates practical experience with offensive security methodology, Windows security, Active Directory attack paths, penetration testing documentation, vulnerability analysis, post-exploitation, and communicating technical findings to both technical and non-technical audiences.
